# Pokémon Search 🔎

A React application that uses the PokéAPI to fetch and explore Pokémon information with a simple search interface.

## ✨ Features

- Fetches the first 50 Pokémon
- Live name search
- Pokémon sprites
- Height and weight information
- Abilities display
- Responsive card-based interface

## 🛠️ Tech Stack

- React
- Axios
- CSS
- PokéAPI

## 🚀 Run Locally

```bash
git clone https://github.com/VARSHITHGORREPATI/Pokemon_Search_App.git
cd Pokemon_Search_App
npm install
npm start
```

Open `http://localhost:3000` in your browser.
